# Art. 39 c) Verpflegungsspesen
1 Dauert eine Ratssitzung mehr als einen halben Tag, so haben die Ratsmitglieder einen Anspruch auf eine pauschale Verpflegungsentschädigung von Fr. 30.–.
2 Kosten für Mahlzeiten werden entschädigt, wenn sie wegen einer amtlichen Verpflichtung auswärts eingenommen werden müssen. Eine Hauptmahlzeit wird pauschal mit Fr. 30.– vergütet. In Ausnahmefällen können effektive höhere Auslagen vergütet werden. Diese sind zu belegen und zu begründen.
